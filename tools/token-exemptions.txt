# Written exemptions. Format: "<file>:<token> <reason>"
#
# AN EXEMPTION IS A WRITTEN DECISION. A line with no reason is not an exemption
# and both gates ignore it. Adding one is a deliberate act, not a way to make a
# red run go green -- if you cannot state why the colour is outside the palette,
# it belongs in the palette.
#
# Key shapes:
#   check-tokens.sh   <file>:<lowercase hex>
#   check-colour.py   <file>:rgb(<r>,<g>,<b>)      (alpha is not part of the key)
#                     <file>:name:<word>           (rule 2, table cell)
#                     <file>:list:<word>           (rule 3, palette enumeration)

# colour it uses as a token and carries no shadow, and the format skills name
# colours only through var(). The shadow and sheet entries that lived here
# went with the formats they covered: an exemption for a file that no longer
# ships reads as coverage and is worse than no line at all.
